适用团队：23级计算机科学与技术1组。组长顾峰鸣（238111541112），成员张誉诚（238111541129）、郝唐鑫（238111541113）、李俊豪（238111541116）。本手册用于四位成员对着评委连续演示；测试截图与程序断言只作为预演证据，不能填写成人工现场通过。

## 演示前准备

使用同一台演示机、一个后端进程和一个本地 MySQL 库。按 README 设置至少 32 字节的独立 `JWT_SECRET`；不要使用 test profile 代替实际 MySQL 启动。演示账号密码 `123456` 仅用于隔离本地演示库。配置界面选择 MOCK_LOCAL，不填写真实 Key，保留默认敏感词 `违法违禁`。先打开登录页，确认学生、教师、管理员都能登录。

已有数据库先备份，再在 MySQL 客户端执行：

```sql
USE flowmind_db;
SOURCE D:/FlowMind/sql/migrations/20261105_add_workflow_yjs.sql;
SELECT column_name, column_type FROM information_schema.columns
WHERE table_schema = DATABASE() AND table_name = 'wf_workflow'
  AND column_name IN ('yjs_state', 'yjs_version');
```

两个字段应同时存在。不要对旧库重新执行含 DROP TABLE 的初始化脚本。前端先 `npm run build`，再 `npm run preview -- --host 127.0.0.1 --port 5173 --strictPort`；后端按 README 启动。准备普通窗口与无痕窗口，避免两人共用 LocalStorage。演示节点连线、保存和翻页各练一次。

退出 Token 检查可在本机 PowerShell 执行，Token 通过隐藏输入读取，不写入报告：

```powershell
$demoSecureToken = Read-Host '退出前的 Token（输入隐藏）' -AsSecureString
$demoToken = [System.Net.NetworkCredential]::new('', $demoSecureToken).Password
try {
  Invoke-RestMethod 'http://127.0.0.1:8080/api/v1/auth/me' -Headers @{ Authorization = "Bearer $demoToken" }
} catch {
  Write-Output $_.ErrorDetails.Message
} finally {
  Remove-Variable demoToken, demoSecureToken
}
```

## 口播边界

Text-to-Flow 是关键词规则合成；配置模型 Key 后，LLM 节点可调用外部厂商，生成图目前仍为规则。知识库从内置 Markdown 词匹配返回来源，不宣称向量检索。协同支持一个后端进程，快照约每2秒写库；异常丢失范围还受网络和数据库影响，不承诺绝不丢失。SSE 调度处使用了虚拟线程，不宣称 WebSocket 全面使用虚拟线程，更不宣称使用 LiteFlow 或 Spring AI。
